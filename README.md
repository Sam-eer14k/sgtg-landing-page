# SG Technology Group

One-page site for SG Technology Group (SGTG), an IT services firm run by
Solomon Greene (in IT since 1993) that serves businesses in New York,
Connecticut and New Jersey. Phone: 347.674.8324.

Plain HTML, CSS and JS with no libraries, so it runs on GitHub Pages as-is. The
same page ships as a WordPress theme.

## What's here

```
index.html          The site. Generated by build.ps1 (CSS and JS inlined). Open it or serve it.
site.webmanifest    Web app manifest (icons, theme colour).
assets/images/      The supplied logo (unchanged), favicons, og-image.jpg,
                    hero posters (WebP, desktop and phone sizes).
assets/video/       sgtg-hero.mp4, the hero background (desktop only, 1600px, ~7 MB).
src/                Sources the site is built from. Edit these, not index.html.
wordpress-theme/    The same site as an installable WordPress theme (PHP).
docs/WIREFRAME.md   The section plan and the job each section does.
build.ps1           Rebuilds index.html and regenerates the theme.
.nojekyll           Tells GitHub Pages to serve assets/ verbatim.
```

## Page sections, top to bottom

Top bar · sticky header (logo on a light plate with the slanted blue edge,
transparent over the hero, solid and blurred on scroll, scrollspy) · hero
(video, word-by-word headline, "SG Network Monitor" panel) · how we work with
you (three expanding stages that auto-cycle) · about (explorable network
diagram, guarantee, Solomon Greene) · stats · services (the one light section;
split panel, accordion on phones) · why businesses stay · symptom picker · what
we support (bento tiles) · industries · trusted by (marquee) · downtime
calculator · security checklist · SG vs. the break-fix guy · process timeline
· case results (before/after drag) · reviews · FAQ (search + accordion) ·
contact · call strip · footer.

Site-wide: section headings animate in word by word with one chrome word,
cards get a cursor spotlight, a lit gradient border and a slight 3D tilt,
glow orbs drift with the mouse, circuit lines draw themselves in, a faint grid
drifts behind dark sections, plus the custom cursor, magnetic buttons and the
back-to-top progress ring. Loops pause when off screen. With
`prefers-reduced-motion`: no cursor, tilt, parallax, video, reveals,
auto-cycling or autoplay, and numbers show their final values.

## The logo

Every placement uses `assets/images/sgtg-logo.png`, a byte-for-byte copy of the
supplied `SGTG Logo.png` (2170 x 725). Nothing recolours it: no filter, blend
mode or opacity on it or its parents. The file has a transparent margin, so
`.logo` crops it with CSS and sets the height only (42px in the header, 34px
when the header shrinks, 32px on phones). It sits on a compact white plate
(24px either side, an angled cut and two thin blue-to-cyan lines) in the
header, footer, mobile menu and comparison table. In the header the logo lines
up with the page's content column at every screen width.
The file is 620 KB. A losslessly cropped copy would be much smaller if you're
happy to use a trimmed version of the file.

## Colours

All colours are CSS variables at the top of `src/css/theme.css`: navy layers

data lines and success states; chrome `#e9edf5` to `#9aa6bf` from the wordmark.
Sections use `tone-a`, `tone-b`, `tone-c` (navy layers) or `tone-light` (the

## View it locally

Open `index.html` in a browser. For the fonts and video to load reliably, serve
it over HTTP rather than `file://`:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```

## Host it on GitHub Pages

1. Create an empty repository on GitHub (no README, no .gitignore, so the first
   push doesn't conflict).
2. Push this folder to it (see below).
3. In the repo, go to **Settings > Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick
   the `main` branch and the `/ (root)` folder, and save.
5. The site goes live at `https://<your-username>.github.io/<repo-name>/` within
   a minute or two.

The folder is already a git repository with its work committed on `main`, so
you only need to add the remote and push:

```bash
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

`index.html` is at the repo root and every path in it is relative, so Pages
serves it as the home page with no extra configuration, including from a
`/<repo-name>/` sub-path. GitHub Pages is case-sensitive; every file reference
has been checked against the real file names. The largest file is the 7 MB
hero video, well under GitHub's 100 MB limit.

Once you know the live address, make link previews work everywhere by giving
`og:image` in `src/_head.html` the full URL (for example
`https://<your-username>.github.io/<repo-name>/assets/images/og-image.jpg`),
then rebuild and push.

To use a custom domain later, add it under **Settings > Pages > Custom domain**
and point the domain's DNS at GitHub as that page describes.

## Editing the site

Edit the sources, not `index.html`:

```
src/_head.html      <head>: title, meta, OG tags, favicons, fonts, structured data
src/_body.html      Markup and all copy, with the SVG icon sprite at the top
src/css/theme.css   All styles, by section; colour tokens on :root at the top
src/js/main.js      All interaction, one labelled module per feature
```

Then rebuild:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

That regenerates `index.html`, rewrites the theme's `style.css`,
`front-page.php` and `assets/js/main.js`, and mirrors `assets/images/` and
`assets/video/` into the theme. `functions.php` and `index.php` are edited in
place.

After a rebuild, commit and push to update the live site:

```bash
git add -A
git commit -m "Describe the change"
git push
```

### Replacing the hero video

Save the new video on the Desktop as `SGTG Hero Background.mp4` (or copy it to
`assets/video/source.mp4`), delete `assets/video/sgtg-hero.mp4`, and run
`build.ps1`. It encodes a 1600px MP4 plus two WebP posters (1920px for desktop,
960px for phones). The video loads after the page has painted, on screens
1024px and wider only; phones, reduced-motion and data-saver visitors see the
poster.

## The WordPress theme

Copy `wordpress-theme/` into `wp-content/themes/`, activate **SG Technology
Group**, then set a static front page under **Settings > Reading**. The form
posts to `admin-post.php` and emails the request with `wp_mail`. Set the inbox
under **Settings > General > SGTG callback email** (it falls back to the admin
email). An SMTP plugin is the usual fix if the host can't send mail.

## Notes

- **The static form doesn't send email yet.** sgtechgroup.com publishes no
  email address. Until one is set in `$LeadEmail` at the top of `build.ps1`,
  the static form thanks the visitor, points them to 347.674.8324 and lets them
  copy their message. With an address set, it opens their email app instead.
- The symptom picker, service buttons and calculator fill in the form's
  "What do you need?" and message fields. Visitors can change them before sending.
- The downtime calculator only multiplies the visitor's own numbers
  (people x hourly cost x hours down) and says so on the page.
- The "Typical break-fix repair" column in the comparison table describes
  break-fix work in general, not a named competitor. Check you're happy with
  the wording.
- No client photos could be downloaded (Wix's image server refuses this
  machine), so the page uses drawn SVG illustrations instead of stock photos.
- Fonts: Saira (headings, set wide to echo the logo), Kumbh Sans (body),
  JetBrains Mono (labels and readouts), all from Google Fonts.
